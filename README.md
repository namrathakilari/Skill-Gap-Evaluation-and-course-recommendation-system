## Quick Start

### 1. Install dependencies
```bash
pip install fastapi uvicorn python-multipart pymupdf easyocr streamlit
```

### 2. Start the server
```bash
uvicorn main:app --port 8000 --reload
```

### 3. Open in browser
| URL | What it is |
|-----|-----------|
| `http://localhost:8000/portal` | DEET Registration Portal |
| `http://localhost:8000/skill-gap` | Skill Gap Quiz (standalone) |
| `http://localhost:8000/docs` | API Swagger UI |

### 4. (Optional) Run Streamlit demo
```bash
streamlit run app.py
```

## Integration Flow

```
┌─────────────────────────────────────────────────────────────┐
│  Option A — Via Streamlit                                    │
│  Upload Resume → Preview → [📋 DEET Portal] or              │
│                             [⚡ Skip to Skill Gap Report]    │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│  Option B — Via DEET Portal                                  │
│  Upload Resume → Fill DEET Form → Submit →                  │
│  [⚡ View My Skill Gap Report]  (appears after registration) │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│  Option C — Direct API                                       │
│  POST /api/v1/resume/analyze  →  302 redirect to            │
│  /skill-gap?deet=<base64-profile>                           │
└─────────────────────────────────────────────────────────────┘
```

### What happens in the Skill Gap quiz when a DEET profile is detected

1. Quiz loads `output/db.json` as normal
2. Reads `?deet=` URL param → decodes base64 JSON profile
3. Maps profile → quiz `ans{}` object:
   - `skills_flat` → `ans.skills` (normalized to match `db.json` casing)
   - Inferred roles → `ans.roles`
   - Education, experience, city → respective `ans` fields
4. Shows a **banner** at the top with the user's name + detected skills
5. Two choices:
   - **⚡ Jump to My Report** — skips all 8 steps, calls `computeGaps()` immediately
   - **✏️ Walk me through quiz** — starts quiz with all answers pre-filled (user can review/edit)
6. Results page shows name, email, DEET score alongside the gap report

## API Reference

| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET`  | `/`  | Redirect to DEET portal |
| `GET`  | `/skill-gap` | Serve Skill Gap quiz HTML |
| `POST` | `/api/v1/resume/parse` | Extract profile JSON from resume |
| `POST` | `/api/v1/resume/analyze` | Extract + redirect to Skill Gap quiz |
| `POST` | `/api/v1/deet/register` | Save confirmed DEET profile, returns `skill_gap_url` |
| `GET`  | `/api/v1/deet/profiles` | List all registered profiles (batch skill gap use) |
| `GET`  | `/api/v1/health` | Health check |

```json
    "email": "tarunchowdary2006@gmail.com",

    "location": "Hyderabad, Telangana",
    "summary": "..."
  },
  "skills": {
    "languages":  ["Python", "Java", "C", "R"],
    "frameworks": ["TensorFlow", "Scikit-Learn", "Pandas", ...],
    "tools":      ["Git", "Github", "MySQL", "GCP", ...],
    "concepts":   ["Machine Learning", "NLP", "Data Science", ...]

  "education":   { "degree_level": "bachelors", "field_of_study": "...", ... },
  "experience":  { "years_category": "0" },
  "preferences": { "preferred_roles": "", "preferred_locations": "Hyderabad" },
  "meta":        { "profile_score": 80 }
}
```
